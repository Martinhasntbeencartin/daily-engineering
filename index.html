How Daily Engineer works

Every day each discipline gets a new problem at each of seven levels. Everyone sees the same problem on the same date, and you can revisit the last 30 days from the Archive.

  • Levels 1–3: hand-picked problems in the spirit of a daily integral. Each needs one key insight and has an exact answer such as $\tfrac{\pi}{4}$, $\ln 2$ or $\tfrac{1+\sqrt5}{2}$.
  • Levels 4–5: multi-part problems that need derivations and coupled equations; values change daily.
  • Level 6, Expert: graduate qualifying-exam depth.
  • Level 7, Mastery: research-grade problems. Bring a calculator or a short script.

Type answers as exact expressions (pi/4, ln(2), sqrt(3)/2) or decimals; a live preview shows how your answer is read. You get five attempts per problem. Revealing the solution marks a problem as reviewed rather than solved. Progress is stored only in this browser.
